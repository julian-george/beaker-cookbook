# Full-pool exclusion reasons

The [exclusion list](excluded_cases.txt) contains 91 of the 600 public cases:
56 task/rubric mismatches, 24 grading defects, and 11 cases without enough
training support for an unstated rule. Each case appears in one bucket.

The reasons below summarize the [source review](https://app.notion.com/p/3e47f5b6b50f817cbf0dd9619a6bb4e6).
Criterion links point to the pinned benchmark source. Criterion numbers are zero-based.
These are optimization-selection decisions, not claims that every excluded task is impossible.
Harness-only limitations remain eligible for code optimization.

The demo also omits six cases outside this list. See the [demo replacement reasons](README.md#why-original-demo-cases-are-replaced).
